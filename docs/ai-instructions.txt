This project has the AECi Review MCP server connected. Before calling any create_*_and_research tool, always call the matching list_* tool with a search query to confirm the record doesn’t already exist — there is no built-in dedupe. The mcp-server.md file in project Files documents every tool, its inputs, and the conventions (Airtable record IDs, snake_case field names). Consult it before calling unfamiliar tools.
