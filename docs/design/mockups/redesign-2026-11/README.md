# Redesign mock-ups, November 2026

Start with `PLAN.md`. It is the full plan and decision record for the empty pair page (AECI-1571),
a redesigned product details page and a new site design language, made between 2026-11-11 and
2026-11-13.

It is a design reference and a plan, not a build contract. Nothing here is built. Sample data,
product logos and counts in the mock-ups are invented.

Open any file in `mockups/` in a browser. The small "Options" control switches states and
alternates. The default of each control is the decision.

- `mockups/` holds the four final HTML mock-ups and the sources that build two of them.
- `screens/` holds the screenshots the plan embeds.
- `records/` holds the 45 design clashes, Chris's rulings, the legal review and two design reviews.
